# SBJ Public Record Contributions

Selected technical artifacts supporting Solutions by Jewel (SBJ) contributions to public consultations, requests for information, and standards work.

The artifacts make specific governance proposals inspectable and reusable. Each is linked to its corresponding SBJ-hosted submission and distinguishes SBJ recommendations from requirements adopted by an institution.

## Browse the collection

See the [technical publication index](index.md) for reviewed publication dispositions and links to the artifacts.

Current artifacts cover:

- NIST AI 200-2 — TEVV-Athlon evidence and authorization
- HM Treasury — agentic payment authorization and evidence
- FedRAMP RFC-0033 — Class D assurance evidence
- NIST SP 800-239 — AI data center authorization controls
- BEREC — generative AI and internet openness

## Relationship to SBJ architecture

These contribution-specific artifacts reference, and do not replace or modify, canonical SBJ governance materials. See the [AI Governance Decision Record](https://github.com/solutionsbyjewel/sbj-ai-governance-decision-record) and [AI Governance Architecture V1](https://github.com/solutionsbyjewel/sbj-ai-governance-architecture-v1).

## Scope and status

A submission or receipt does not indicate institutional endorsement, adoption, or acceptance. The index identifies the current review disposition for this selected set; it is not a determination about every contribution in SBJ's broader pipeline.

This repository remains private. No public-release or reuse license has been assigned.
