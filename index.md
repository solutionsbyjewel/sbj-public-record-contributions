# SBJ Public Record Contributions — Technical Publication Index

> **Draft review material. Not approved for public release.** This repository is private. The contents below are SBJ-authored summaries for review, not agency endorsements, acceptance statements, or substitutes for the formal submissions.

This repository is intended to hold selected, reusable technical summaries linked to SBJ Public Record Contributions (PRCs). Selection is independent of institutional importance: a PRC is included as a technical note only when its submitted recommendations offer inspectable and reusable substance. Canonical SBJ architecture and Decision Record materials remain in their existing repositories; this index cross-references rather than republishes them.

## Review controls

- Preserve each formal contribution's identity and link to its SBJ-hosted record.
- Treat these notes as summaries of recommendations, not validated models, tests, or implementation results.
- Verify factual claims, public-release suitability, and applicable rights before any public release.
- Do not infer institutional endorsement or acceptance from a submission or receipt.
