# PRC-028 — BEREC: Generative AI and Internet Openness

> **Draft review material. Not approved for public release.** This is an SBJ-authored summary of recommendations in the formal contribution; it is not a BEREC position or endorsement.

**Formal contribution:** [SBJ-hosted submission](https://berec-generative-ai.solutionsbyjewelgovernance.workers.dev/)

## Technical substance identified

The submission advances five proposals:

1. Treat delegated agent action as relevant to internet openness.
2. Support attributable authorization in MCP/WebMCP contexts.
3. Establish verifiable automated-client identity and access purpose.
4. Preserve minimum user controls.
5. Develop standards work and monitoring for agent protocols.

These are policy and governance proposals. This note does not claim a published protocol specification, standardized control, or measured implementation.

## Reuse opportunity

The proposals provide a practitioner-facing lens for discussing automated clients, delegated authority, user controls, and protocol governance in open-internet contexts. Any more detailed technical model would require separate evidence and review.
